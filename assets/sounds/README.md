# Application Sounds

The Sales checkout currently plays `cash-register-sound.wav` after a sale is
completed successfully.

The following feedback sounds were created specifically for this project using
additive synthesis. They contain only mathematically generated waveforms and do
not incorporate downloaded recordings, sample-library content, or other
third-party audio:

- `transfer-received.wav`: inventory transfer completed
- `oms-connected.wav`: OMS connection succeeded
- `oms-connection-failed.wav`: OMS connection failed

- Duration: 1.35 seconds
- Format: 44.1 kHz, 16-bit mono WAV
- Design: two mechanical register clacks followed by a metallic bell and rebound
